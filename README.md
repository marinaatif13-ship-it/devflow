# DevFlow

DevFlow is a clean, responsive collection of free developer utilities built with React and Vite.

## Included tools

- JSON Formatter
- Color Generator
- Password Generator

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Tech stack

- React
- Vite
- React Router
- React Icons
- CSS
